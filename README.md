## FAQ

### What is XCutors?

XCutors is a curated Windows desktop collection that bundles several popular Roblox script executors — Volt, Synapse Z, Potassium, Wave — along with a universal loader called xcutorsLoader that simplifies installation and management of all of them.

### Is XCutors free to use?

The xcutorsLoader and the repository itself are free. However, some bundled executors may have their own pricing or key-system requirements set by their original developers.

### Which Windows versions are supported?

XCutors supports Windows 10 (version 1903 and later) and Windows 11, both 64-bit. A minimum of 4 GB RAM and .NET Framework 4.8 or newer is recommended.

### Windows Defender flags the executor — is it safe?

Roblox executors commonly trigger false positives because they inject into external processes. Always download from this official GitHub repository only. You can verify file hashes listed in each release to confirm integrity. Add an exclusion for the install folder if needed.

### How do I update the executors?

xcutrsLoader includes a built-in auto-updater. When you open the loader, it checks for new versions of each installed executor and prompts you to update with one click.

### Can I use multiple executors at the same time?

You can install all executors side-by-side, but you should only attach one executor to a Roblox instance at a time to avoid conflicts. The multi-instance feature lets you attach different executors to separate Roblox windows.

### Where can I find scripts to use?

XCutors ships with a built-in script hub organized by game and category. You can also load external .lua files from disk or paste scripts directly into the editor. Community script links are shared in the repository's Discussions tab.

### The executor is not attaching to Roblox — what should I do?

First, make sure you are running the executor as Administrator. Then confirm Roblox is fully loaded into a game (not just the lobby). If the issue persists, try disabling your anticomponent exclusion temporarily and restarting both applications.

### Does XCutors work on Roblox UWP (Microsoft Store) versions?

Compatibility depends on the individual executor. Wave and Potassium support both the standard and UWP versions. Check each executor's documentation inside the loader for specific details.

### How do I uninstall an executor?

Open xcutrsLoader, navigate to the Installed tab, and click Remove next to the executor you want to uninstall. This deletes the executor files and cleans up associated registry entries. You can also manually delete the install folder.
